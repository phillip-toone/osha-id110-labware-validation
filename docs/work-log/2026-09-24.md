## Findings Requiring Investigation

### 1460 QCSM recovery

The 1280 QCSM recovery component (`1280 F/T`) calls the `CALC_QC_CONC` subroutine and has configured calculation variables for found and theoretical values.

The corresponding `1460 F/T` component currently has a calculation record but no source code and no calculation variables.

The 1460 QCSM recovery implementation therefore requires further investigation. The existing 1280 implementation and `CALC_QC_CONC` subroutine should be fully understood before changes are made.

### 1460 QCSM final calculation

The 1460 QCSMs correctly calculated their expected fluoride masses.

However, LabWare subsequently attempted the air-volume-dependent `1460 (Final)` calculation on the QCSMs. Because QCSMs do not have a meaningful air volume, this generated reproducible divide-by-zero runtime errors.

The intended QCSM calculation path needs to be reviewed.

### QCSM coverage

A complete OSHA ID-110 analysis requires both particulate fluoride (1280) and HF (1460).

The current validation batch contained the 1460 `QCSM036` set but not the 1280 `QCSM035` set. Future recycled runs of this reference case should include both QCSM sets.

### Batch Calculate

`Batch -> Calculate` exhibited abnormal behavior during this run, including repeated prompts concerning already-entered batch components, repeated calculation errors, and loss of some previously entered batch traceability values.

This behavior requires separate investigation.

## Other Observations

The generic LabWare `ISE` analysis contains optional components for multiple ISE methods, including future chlorine/ID-101 functionality. The appearance of `Cl F/T` in the user interface does not by itself indicate that a chlorine result has been assigned to an ID-110 sample.

Sample `65719` was cancelled during interactive testing. Audit history recorded `CancelTest` with reason `Calculation Update`. This is currently considered an execution artifact rather than a confirmed LabWare defect.

`Batch -> Batch Process Results` was confirmed to be the instrument-file processing pathway. Instrument integration is intentionally deferred until the underlying ID-110 analytical implementation is functioning correctly.
