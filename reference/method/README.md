\# OSHA ID-110 Method References



This directory contains method-level reference documents applicable across

all validation cases and LabWare validation runs in this repository.



\## OSHA Method



`osha-id110.pdf`



Public OSHA ID-110 analytical method for fluoride/hydrogen fluoride by

ion-selective electrode.



\## Internal Work Instruction



`Work Instruction for OSHA ID110 Flouride (F and HF) .docx`



Internal laboratory work instruction implementing OSHA ID-110.



The filename is preserved as supplied, including the spelling of "Flouride."



\## Scope



These documents are method-level references and should not be duplicated

under individual `cases/` or `runs/` directories.



Case-specific historical records belong under `cases/`.

Execution-specific LabWare records belong under `runs/`.
